# Destini 🔀

A choose-your-own-adventure story app built with Flutter. Read a story 
segment, pick between two choices, and watch the narrative branch toward 
one of several different endings.

## Features
- Branching story logic driven by a dedicated `StoryBrain` class
- Dynamic UI that shows/hides the second choice button depending on story state
- Restart flow once an ending is reached

## Tech Stack
- Flutter & Dart
- Stateful widgets for UI updates
- Object-oriented story/state modeling (`Story` and `StoryBrain` classes)

## Getting Started
\`\`\`bash
flutter pub get
flutter run
\`\`\`
